    Grand Luxe Hotel Reservation System

    Project Description
A web-based hotel reservation system that allows customers
to register, log in, explore rooms, and make reservations.
Administrators can manage customer bookings.

     Technologies Used
- HTML
- CSS
- JavaScript
- Supabase
- GitHub
- Netlify

       Main Features
- Customer registration and email verification
- Customer login
- Room browsing
- Online room booking
- Customer booking history
- Admin dashboard
- Booking confirmation and cancellation

      Live Website
https://profound-crostata-1c79bd.netlify.app

       Database
Supabase is used for authentication and database management.
